# Prof. Behrouz Minaei-Bidgoli - Faculty Website

Official academic faculty website for **Prof. Behrouz Minaei-Bidgoli**, School of Computer Engineering, Iran University of Science and Technology (IUST).

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```

### 4. Sync Google Scholar Publications
```bash
npm run sync:scholar
```
